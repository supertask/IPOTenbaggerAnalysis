## お気に入り銘柄をTSVに書き出す

重いデータ（期中の報告書、AIによる読み解きなど）の対象は「保有銘柄系」に絞っている
（方針は `CLAUDE.md`）。その3区分のうち、自分とテンバガーXは
`data/output/portfolio/*.tsv` にあるが、**お気に入りはGoogleスプレッドシートにしか無く、
コードからは見えていない**。

スプレッドシートの「お気に入り」タブは見出し（銘柄コード / 銘柄名 / メモ）だけ
入れてあり、中身はまだ空。埋まったら `data/output/portfolio/favorites.tsv` として
同じ形式で書き出せば、`portfolio_codes()` が読むので自動で対象に入る。
`visualizer/portfolio.py` のラベル側は登録済みなので、TSVを置けば画面にも出る。

お気に入りは保有していない監視銘柄なので、株数や金額の列は要らない。

書き出したあとにやること:

```bash
python collectors/interim_report_collector.py
python -m visualizer.build_index
python collectors/facility_count_collector.py --interim
```

## AI分析を保有外の銘柄にも広げる

テンバガー条件のうち、機械では判定しきれない3つをAIに任せたい。

| 条件 | 内容 | 現状 |
|---|---|---|
| 2 | 成長性の高いビジネスモデル（ストック型／多店舗展開型／営業人員依存型） | 保有銘柄のみ手動分類済み |
| 6 | ニッチ市場でトップ／オンリーワン | 同上 |
| 7 | 保証ビジネス | キーワードで暫定判定 |

### 分担の方針

- **保有銘柄（テンバガーX・自分のポートフォリオ）** … Claudeで分類し、
  `data/meta/business_model.tsv` に手で書く。数が少なく（30銘柄程度）、
  判断の質が投資判断に直結するため。
- **それ以外の全銘柄（1,300社超）** … **OpenRouterの無料モデル**で一括処理する。
  量が多くコストをかけられないので、多少精度が落ちても網羅を優先する。

### やること

1. `collectors/ipo_ai_summary.py` は現状 Groq 固定なので、OpenRouter を
   使えるようにする（`OPENROUTER_API_KEY`、モデル名を設定で切り替え）
2. 出力先 `data/output/ai_summary/all_companies.tsv` には既に
   ビジネスモデル名・参入障壁・保証数などの列があるので、その形式に合わせる
3. `visualizer/tenbagger_criteria.py` から ai_summary を読んで条件2/6/7に反映する
   （現在は `business_model.tsv` の手動分類しか見ていない）
4. 手動分類とAI分類が両方ある場合は手動を優先し、AI由来であることが
   画面で分かるようにする（根拠パネルに出典を出す）

### 注意

- 現在の `ai_summary/all_companies.tsv` は6社ぶんしか無く、visualizerからは
  参照されていない
- 6社の出力を見た限り「テンバガーになりそうか」は全社Falseで、理由に
  「情報不足」「不特定」が混じる。プロンプトの調整が要る

## 期中の持株を全銘柄に広げるか

`collectors/interim_report_collector.py` は、期中の報告書（中間期の四半期報告書・
半期報告書）から大株主を拾って持株の推移を年2回にする。ただし対象は
`data/output/portfolio/*.tsv` の保有銘柄だけに絞っている。

全上場企業に広げる場合の見積り:

- 書類数は保有32銘柄で約350件。全銘柄（4,100社超）だと数万件になり、
  EDINETへのリクエストとディスク使用量が跳ね上がる
- 第1・第3四半期報告書には大株主が載らないため、落とした書類の約2/3は
  持株の観点では空振りになる（財務指標としては使える）
- 役員の持株は期中の報告書には載らないので、増やしても大株主だけ

広げるなら、まず「一覧で見えている銘柄だけ」など段階を踏むのが無難。

## 一覧の「注目度」表示

注目度（S/A/B/C/D）は公開価格に対して初値がどれだけ上がるかの予想で、企業の
成長性とは別物。セカンダリ投資の判断材料としては誤解を招くので、表示位置を
下げるか外すかを決める。
