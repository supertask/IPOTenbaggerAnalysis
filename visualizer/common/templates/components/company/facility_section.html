拠点あたりの採算
{% if facility.ratio_to_peers %} 競合中央値の {{ '%.1f'|format(facility.ratio_to_peers) }}倍 {% endif %}
拠点数有価証券報告書の本文（事業の内容 / MD&A / 業績等の概要 / 経営方針）から 「○○店舗」のような記述を拾っています。標準化された開示項目ではないためタグが無く、 文章から取るしかありません。複数の箇所に同じ数字が出るものを優先しています。
売上・利益XBRLの当期値（売上高、営業利益。無い場合は経常利益）。こちらはタグ付けされているので確実です。
1拠点あたり売上（利益）÷ 拠点数。同じ期の値どうしで割っています。
競合との比競合企業のうち拠点数が取れた会社の「1拠点あたり利益」の中央値と比べた倍率です。 1拠点あたりの水準は業態で桁が違うので、単体の数字ではなくこの比で見てください。
注意拠点数は年によって連結・単体など別の定義の数字を拾うことがあります。 推移が不自然に飛んでいる期は疑ってください。

原価の構成

仕入が原価に
占める割合		当期仕入高 ÷ 売上原価。仕入高は「売上原価明細書」の本文から拾っています。 この表はテキストにすると金額と構成比が連結するため、桁区切りの形に厳密に一致させたうえで、 項目名の直後の2つ目の数字（＝当期）を取っています。
労務費が原価に
占める割合		労務費 ÷ 売上原価。仕入高と同じ明細書から取っています。
