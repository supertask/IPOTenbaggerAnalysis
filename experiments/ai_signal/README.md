# AI評価に投資判断の役に立つ信号があるか

事業内容の文章だけを見てAIが付けた評価が、その後の株価倍率と関係するかを試した。
関係が無ければ、その問いを1,300社に流しても意味のない列が増えるだけなので、
先に小さく確かめる。

## やり方

- 母集団: 2015〜2020年に上場した447社（経過年数を揃えるため期間を限定）
- 標本: 乱数で60社（seed固定）
- 出題: 銘柄コード・業種・事業内容（1〜2行）だけ。**倍率は伏せた**
- 評価者: Claude
- 付けたラベル
  - **成長ドライバー**: 何が増えると売上が増えるか（拠点数／契約積み上げ／人員数／その他）
  - **ポテンシャル**: 事業内容から見た総合評価（高／中／低）
- 採点: ラベルごとに `最大何倍株` と `現在何倍株` の中央値を比較

```
python experiments/ai_signal/sample.py   # 出題と答えを分けて生成
python experiments/ai_signal/score.py    # 採点
```

## 結果

### 成長ドライバー（現在何倍株の中央値）

| ラベル | 社数 | 中央値 | 3倍以上 |
|---|---|---|---|
| 拠点数 | 5 | **2.90** | 40% |
| 人員数 | 15 | **2.20** | 40% |
| その他 | 29 | 1.10 | 3% |
| 契約積み上げ | 11 | 0.90 | 9% |

### ポテンシャル評価

| ラベル | 社数 | 現在何倍株の中央値 | 最大何倍株の中央値 |
|---|---|---|---|
| 高 | 5 | 1.90 | 7.30 |
| 中 | 32 | 1.40 | 3.60 |
| 低 | 23 | 0.90 | 3.40 |

順位相関は 最大何倍株で **+0.118**、現在何倍株で **+0.237**。ほとんど効いていない。

## わかったこと

**1. 総合評価（ポテンシャル高中低）は使えない**

順位相関が0.1〜0.2しかない。「中」と付けた32社の10倍以上は0%、「低」と付けた23社は13%で、
順序が逆転している。実際に伸びた上位5社のうち3社（ブランジスタ28倍、ケイアイスター不動産23倍、
グローバルウェイ16倍）を「低」と判定していた。

**2. 成長ドライバーの分類には差が出た**

拠点数・人員数と、その他とで中央値が2倍以上違う。3倍以上になった比率は40%対3%。
構造化された問い（何が増えると売上が増えるか）は、総合評価より扱いやすい。

**3. 「契約積み上げ」が最下位だった**

ストック型が最も有望という前提と逆の結果。ただしこれは事業モデルの優劣ではなく、
2015〜2020年に上場したSaaS企業が高い評価で上場し、その後に評価が下がったことの
影響が大きいと考えられる。上場時のPERを併せて見ないと切り分けられない。

## この結果の限界

**評価者が結果を知っている銘柄がある。** ベイカレント（82.7倍）とアンビス（7.3倍）は
有名な成功例で、評価者がそれを知った状態で「高」を付けている。ポテンシャル「高」5社の
平均を押し上げているのはベイカレント1社なので、この群の数字はそのまま信じられない。
本来は評価者が結果を知り得ない条件で試す必要がある。

**標本が小さい。** 拠点数もポテンシャル「高」も5社しかない。差が出ているように見えても
偶然の範囲を出ない。

**最大何倍株は目標として粗い。** 一時的な急騰も拾うため、全体の中央値が3.6倍と高く出る。
現在何倍株のほうが差がはっきり出た。

# 第2ラウンド: 条件を厳しくして確かめ直した

第1ラウンドの限界を3つとも潰した。

- **銘柄コードを伏せて連番IDにした**（前回はコードから有名企業を特定できた）
- **200社に増やした**（前回は群によって5社しかなかった）
- **第1ラウンドの60社を除いた**（答えを知ってしまっているため）

効かないと分かった総合評価は捨て、成長ドライバーの分類だけを付け直した。

```
python experiments/ai_signal/sample2.py
python experiments/ai_signal/score2.py
```

## 結果: 第1ラウンドの信号は再現しなかった

### 現在何倍株

| ラベル | 社数 | 中央値 | 第1ラウンドでの中央値 |
|---|---|---|---|
| 拠点数 | 19 | 1.00 | 2.90 |
| 人員数 | 28 | 1.05 | 2.20 |
| 契約積み上げ | 62 | 1.10 | 0.90 |
| その他 | 91 | **1.50** | 1.10 |

第1ラウンドで最下位だった「その他」が最上位になり、最上位だった「拠点数」が最下位になった。
順序がほぼ逆転しており、**第1ラウンドで見えた差は偶然だった**と考えるのが妥当。

原因は2つ。群あたり5社しかなかったこと、そして評価者が有名企業を特定できていたこと。

### 最大何倍株

| ラベル | 社数 | 中央値 | 2倍以上 |
|---|---|---|---|
| 契約積み上げ | 62 | 4.40 | 94% |
| その他 | 91 | 3.90 | 92% |
| 人員数 | 28 | 3.40 | 93% |
| 拠点数 | 19 | 2.60 | 79% |

こちらもラベル間の差は小さく、どの群も9割前後が2倍以上に達している。
最大何倍株は一時的な急騰を拾うため、銘柄の選別には向かない。

## むしろはっきり出たのは上場時のPER

| 上場時PER | 社数 | 現在何倍株の中央値 | 3倍以上 |
|---|---|---|---|
| 20倍以下 | 88 | 1.45 | 23% |
| 20〜40倍 | 60 | 1.35 | 27% |
| 40倍超 | 49 | **0.60** | **8%** |

PER40倍超で上場した銘柄は、中央値が1倍を割っている。層別すると、どのドライバー群でも
40倍超が最も悪い。事業内容から読み取ったラベルより、**上場時にいくらで買えたかのほうが
その後の株価をよく説明している**。

これは11条件のうち条件11（PER40倍以下、理想は20倍以下）がそのまま効いているということで、
AIに新しく判断させるまでもなく、既にチェックリストで機械的に判定できている項目である。

## 結論

**事業内容の文章からAIに評価させても、株価の予測には使えなかった。**
総合評価も成長ドライバーの分類も、どちらも再現性のある信号を示さなかった。

したがって、**1,300社にAI分類を流す作業は、株価予測を目的とする限り見送るべき**。
費用に見合う信号が確認できていない。

ただしこれは「AI分類に価値がない」という意味ではない。11条件のうち条件2（ビジネスモデル）は
チェックリストの表示項目であり、**投資判断の枠組みを人に見せるという用途では引き続き有用**。
予測の道具としては使えない、という結論に留まる。

## 限界

- 標本は2015〜2020年上場の日本株のみ。他の期間や市場では違う結果になりうる
- `現在何倍株` は上場後の経過期間で変わるが、上場年を揃えたうえで期間内のばらつきは残る
- PERの効果は「割安に買えた」ことの反映であると同時に、そもそも成長期待の低い企業が
  低PERで上場している面もあり、因果関係までは言えない

# 第3ラウンド: 1単位あたりの採算を競合と比べる

「1拠点あたりの売上・利益を競合と比べれば、その事業モデルが実際に効いているか
分かるのでは」という仮説の検証。

**店舗数はどこにも無かった。** all_companies に列が無く、XBRLにも標準の要素が無い
（`NumberOfStores` などは0件）。店舗数は有報の本文には書かれているが、タグ付けされて
いないため機械では取れない。代わりに **従業員数**（97%の銘柄で取れる）を単位に使った。

比較の相手は2通り。競合企業（登録がある131〜134社）と、同業種の中央値（189〜192社）。

```
python experiments/ai_signal/score3.py
```

## 結果: どれも相関しなかった

| 指標 | 社数 | 順位相関 |
|---|---|---|
| 1人あたり経常利益（絶対値） | 196 | +0.135 |
| 1人あたり経常利益 ÷ 競合の中央値 | 134 | +0.060 |
| 1人あたり売上 ÷ 同業種の中央値 | 189 | +0.048 |
| 1人あたり経常利益 ÷ 同業種の中央値 | 192 | +0.025 |
| 1人あたり売上 ÷ 競合の中央値 | 131 | +0.011 |

4分位に分けても単調にならない。たとえば「1人あたり売上 ÷ 競合」では、
**下位25%の中央値が1.60倍で最も高く**、上位25%は1.30倍だった。順序が逆で、
かつ群間の差も小さい。

## この結果をどう読むか

**仮説そのものを否定したわけではない。** 試せたのは次の形に限られる。

- 店舗単位ではなく**従業員単位**。多店舗展開型の企業では、1人あたり売上は
  1店舗あたりの採算をあまり表さない
- 上場時点の**スナップショット**。仮説の本来の狙いは「規模を広げながら採算を
  保てているか」という**推移**のはずで、1時点の値では捉えられない

推移で見る形は、実は既に可視化側に入っている（財務指標の「従業員一人当たり営業利益」を
競合と重ねたチャート）。今回の結果はそれを否定するものではない。

## ここまでの3ラウンドで言えること

事業内容の総合評価、成長ドライバーの分類、1単位あたりの採算。3つとも
現在何倍株との相関はほぼゼロ（-0.02〜+0.24）だった。一方で上場時のPERは、
40倍超の群の中央値が0.60倍、3倍以上に達したのは8%と、はっきり差が出ている。

上場時点で取れる断面のデータからは、**いくらで買えたか以上の情報は取り出せていない**。
銘柄の中身で差を付けたいなら、断面ではなく上場後の推移（売上・利益・採算が
実際に伸びているか）を追う必要がある。
