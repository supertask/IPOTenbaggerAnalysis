# ポートフォリオのスクリーンショットから保有銘柄を起こす手順

SNS等に投稿された証券口座のポートフォリオ画面（SBI証券など）の画像から、
銘柄コード・銘柄名・保有株数・保有割合を起こして TSV と Google スプレッドシートに保存する。

画像の文字起こしは自動化していない。OCRは銘柄コードの英字混在（`141A` 等）や
桁区切りの誤読が起きやすく、投資判断に使う数字を壊すため、目視で読む前提にしている。
計算とTSV出力だけを `collectors/portfolio_screenshot_parser.py` が担当する。

## 手順

### 1. 画像を取得する

```bash
curl -sL -o /tmp/portfolio.jpg "<画像URL>"
```

### 2. 分割・拡大して読み取る

そのまま読むと桁を間違えるので、ポートフォリオの表部分だけを切り出し、
2倍以上に拡大してから読む。

```python
from PIL import Image
im = Image.open("/tmp/portfolio.jpg")
crop = im.crop((left, top, right, bottom))
crop.resize((crop.width * 2, crop.height * 2), Image.LANCZOS).save("/tmp/crop_0.png")
```

読み取り時に必ず確認すること:

- **マスクされた行がないか** — 投稿者が意図的に白塗りしている場合がある。
  復元や逆算はせず `(非開示)` として記録し、割合の分母から外す。
- **画面が途中で切れていないか** — 「株式（信用）」など下端で切れたセクションは
  データに含まれない。何が欠けているかをメモに残す。
- **同じ銘柄が複数口座に出ていないか** — 特定預りとNISA預りの両方に同じコードが
  出ることがある。合算するかどうかを決める。
- **検算** — `保有株数 × (現在値 - 取得単価)` が画面の評価損益と一致するか。
  一致しなければどこかを読み違えている。

### 3. Holding に起こす

```python
from collectors.portfolio_screenshot_parser import (
    Holding, merge_duplicates, to_rows, write_tsv,
)

HOLDINGS = [
    Holding("5843", "ニッポンインシュア", 52000, 835, 2443, 83616000, ["特定"]),
    # 読み取れない行は None を入れ、note に理由を書く
    Holding("(非開示)", "(非開示)", None, None, None, 23328000, ["特定"],
            note="スクショ上でマスクされており判読不可"),
]

rows = to_rows(merge_duplicates(HOLDINGS))
write_tsv(rows, "tenbagger_x")   # -> data/output/portfolio/tenbagger_x.tsv
```

引数の順は `コード, 銘柄名, 保有株数, 取得単価, 現在値, 評価損益, 口座区分リスト`。

### 4. Google スプレッドシートに書く

- データタブ（例: `テンバガーX`）には **ヘッダー1行 + データ行のみ** を書く。
  合計行・注記・出典はプログラムから読むときに邪魔になるので入れない。
- 出典・前提・欠損の理由などは `メモ` タブに `対象タブ / 項目 / 内容` の3列で書く。
- 書き込む前に既存内容を `get_values` で確認する。空でなければ上書き可否を確認する。

## 保有割合の定義

```
保有割合% = 評価額(保有株数 × 現在値) ÷ 評価額が判明した銘柄の合計
```

金額が読み取れない銘柄は分母から除外し、割合欄は空にする。
口座残高や信用建玉を分母に含めたい場合は `to_rows()` を使わず個別に計算する。

## 出力

| 出力先 | 内容 |
|---|---|
| `data/output/portfolio/<name>.tsv` | 9列のTSV（UTF-8・タブ区切り） |
| Google スプレッドシート | データタブ＋メモタブ |

TSVの列: `銘柄コード / 銘柄名 / 保有株数 / 取得単価 / 現在値 / 評価額 / 評価損益 / 保有割合% / 口座区分`
