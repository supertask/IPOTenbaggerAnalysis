# 財務指標の比較の、見どころを書く

`data/meta/metric_reading.tsv` に1銘柄1行。詳細ページ下部
**「財務指標の比較」の見出しの直下**に、AIによる解釈のカードとして出る。

対象は保有銘柄のみ（自分・テンバガーX・お気に入り）。全銘柄には広げない。

## なぜ要るか

比較チャートは自社＋競合で30枚近く並ぶ。**全部見るのは無理だし、全部見る必要もない。**
どれを見ればこの会社の良し悪しが分かるのかを、先に3つだけ示す。

数字そのものはグラフが持っているので、**ここに数字を並べ直さない。**
書くのは「見る順番」と「そのまま読むと誤るところ」。

### ここに書かないもの

**指標そのものの説明は書かない。** 各グラフの「?」に入っている
（`visualizer/metric_help.py`）。あちらは全銘柄で共通の定義と一般的な読み方で、
AIの解釈ではない。ここに書くのは**その銘柄の話**だけ。

## 手順

### 1. 数字を出す

```bash
python collectors/metric_compare_dump.py 212A            # 年ごとの値も出す
python collectors/metric_compare_dump.py 212A --brief    # 直近と年平均だけ
python collectors/metric_compare_dump.py --portfolio --brief
```

グラフと同じデータ源から取るので、ここに出る数字は画面と一致する。
指標ごとに、直近の値・年平均成長率・競合の中での順位が出る。

- 率（営業利益率・ROE・自己資本比率）は%に直してある
- PER・PEGは小さいほうが上位として順位を付ける。ただし赤字の会社が混ざって
  負の倍率になる場合は順位を出さない（意味がないため）
- 単位は指標ごとに1つに揃えてある。年で切り替わらない

### 2. TSVに1行足す

| 列 | 書くこと |
|---|---|
| コード / 銘柄名 | |
| 見どころ | **まずどれを見るか。3つまで。** なぜそれを見るのかを1文で |
| 競合との差 | 同じ土俵の会社と並べて何が違うか。**数字で** |
| 気をつける点 | そのまま読むと誤るところ |
| 出所報告日 / 作成日 | |

各項目2〜3文。長く書かない。

### 3. 「見どころ」の選び方

その会社の**稼ぎ方の型**（`business_profile.tsv` の「稼ぎ方の型」）で変わる。

| 型 | まず見るもの |
|---|---|
| 多店舗展開型 | 売上高の伸び、営業利益率、**フリーCFと有利子負債÷純資産**（出店を借入で回していないか） |
| ストック型 | 売上高の伸びと営業利益率の**両方**（解約が増えると伸びだけ落ちる）、売上総利益率 |
| 営業人員依存型 | 総人員あたり営業利益（増員が利益になっているか）、売上総利益率 |

どの型でも、**伸びと採算を1組**で見る。売上だけ伸びて利益率が落ちていれば、
成長は買っているだけかもしれない。

小型株を狙う前提では、次の3つはどの型でも1度は確かめる。

- **時価総額** … 小さいほど倍率は伸びる。同じ事業で1桁小さい競合がいないか
- **利益の質（営業CF÷営業利益）** … 1.0を割る状態が続いていないか。
  帳簿の利益が現金になっていない会社は、伸びていても危ない
- **PEGレシオ** … リンチの目安で1.0が適正、0.5未満で割安。
  PERが高くても成長が速ければ割高とは限らない

### 4. 「気をつける点」に必ず書くもの

実データで踏んだもの。当てはまるときは書く。

- **「従業員一人当たり営業利益」の分母は正社員だけ。** 平均臨時雇用人員は
  入っていない。パートの比率が高い会社ほど良く見える。フィットイージーは
  正社員65人・臨時211人（総人員の76%）で、この指標は35.6百万だが、
  総人員276人で割ると8.4百万になり、臨時7人のFFJ（7.0百万）とほぼ並ぶ。
  **一度これを「FFJの5倍」と書いて間違えた。** 従業員数と平均臨時雇用人員の
  2枚を必ず一緒に見る
- **競合が同じ土俵か。** 持株会社が競合に入っていると営業利益率が跳ねる
  （フィットイージーの競合カーブスHは84%。フランチャイズのロイヤリティ収入が
  中心の持株会社なので、直営店を持つ会社と並べても意味がない）
- **上場したばかりで年数が足りない。** 年平均成長率が2〜3期から出ていると、
  1回の跳ねがそのまま倍率になる
- **株式分割でEPSが不連続。** フィットイージーは1:1,000分割をまたいで
  2021年48,189円→2022年3.68円。年平均成長率は成長性を表さない
- **PEGが負。** EPSが減っている会社では意味を持たない
- **決算期が競合とずれている。** 直近同士を比べているつもりが1年ずれる
- **同じ値が2期に入っていることがある。** フィットイージーは2024-02-01と
  2025-01-31の純資産・総資産・当期純利益が同値。1期ぶん重複している

### 全部の指標に目を通す

**17項目ある。** 上から11項目だけ見て書くと、下のほうにある平均臨時雇用人員を
見落として、上のような読み違いをする。`--brief` の出力を最後まで通す。

### 5. 守ること

- **グラフに出ていないことを書かない。** ここは読み方であって、
  新しいデータを持ち込む場所ではない
- 数字は `metric_compare_dump.py` の出力と一致させる
- 良い点と悪い点を両方書く。3つとも良い話なら見どころの選び方を疑う
- 判定（買う・売る）は書かない。それは総括（`holding-profile`）の仕事

### 6. 確認する

```bash
python -m visualizer.app
python scripts/verify_visualizer_deep.py
```

「財務指標の比較」の見出しの下に出ること。スマホ幅でも崩れないこと。
