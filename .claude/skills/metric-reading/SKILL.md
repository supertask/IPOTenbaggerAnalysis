# 財務指標の比較の、見どころを書く

`data/meta/metric_reading.tsv` に1銘柄1行。詳細ページ下部
**「財務指標の比較」の見出しの直下**に、AIによる解釈のカードとして出る。

対象は保有銘柄のみ（自分・テンバガーX・お気に入り）。全銘柄には広げない。

## なぜ要るか

比較チャートは自社＋競合で30枚近く並ぶ。**全部見るのは無理だし、全部見る必要もない。**
どれを見ればこの会社の良し悪しが分かるのかを、先に3つだけ示す。

数字そのものはグラフが持っているので、**ここに数字を並べ直さない。**
書くのは「見る順番」と「そのまま読むと誤るところ」。

### ここに書かないもの

**指標そのものの説明は書かない。** 各グラフの「?」に入っている
（`visualizer/metric_help.py`）。あちらは全銘柄で共通の定義と一般的な読み方で、
AIの解釈ではない。ここに書くのは**その銘柄の話**だけ。

## 手順

### 1. 数字を出す

```bash
python collectors/metric_compare_dump.py 212A --diagnose          # 必ずこれ
python collectors/metric_compare_dump.py 212A --brief --diagnose   # 年ごとの値を省く
```

**`--diagnose` を付けずに書かない。** 指標を縦に並べただけでは、書けることが
「売上が伸びている」で止まる。効くのは組み合わせと比較の相手で、そこは
並べただけでは出てこない。`--diagnose` を付けると次の4つが足される。

| 足されるもの | 何が分かるか |
|---|---|
| **所見** | 組み合わせでしか読めないもの。「売上↑なのに利益率↓」「ROE↑なのにROA→（借入で嵩上げ）」「営業CFが営業利益に届かない期が続く」を機械で当てる |
| **同じ業種の中央値** | 営業利益率23.8%が高いのかは業種で変わる。上位何%かも出る |
| **何倍になったかで分けた比較** | 上場N年目に、10倍以上／3〜10倍／2倍未満だった会社がそれぞれどういう数字だったか。**見分ける力の無い指標には印が出る**（下記） |
| **データの欠け・異常** | 比較できていない指標、同じ値が2期続いている（期の重複）など |

グラフと同じデータ源から取るので、上半分の数字は画面と一致する。
指標ごとに、直近の値・年平均成長率・競合の中での順位が出る。

- 率（営業利益率・ROE・自己資本比率）は%に直してある
- PER・PEGは小さいほうが上位として順位を付ける。ただし赤字の会社が混ざって
  負の倍率になる場合は順位を出さない（意味がないため）
- 単位は指標ごとに1つに揃えてある。年で切り替わらない

### 2. TSVに1行足す

| 列 | 書くこと |
|---|---|
| コード / 銘柄名 | |
| 見どころ | **まずどれを見るか。3つまで。** なぜそれを見るのかを1文で |
| 競合との差 | 同じ土俵の会社と並べて何が違うか。**数字で** |
| 気をつける点 | そのまま読むと誤るところ |
| 出所報告日 / 作成日 | |

各項目2〜3文。長く書かない。

### 3. 「見どころ」の選び方

その会社の**稼ぎ方の型**（`business_profile.tsv` の「稼ぎ方の型」）で変わる。

| 型 | まず見るもの |
|---|---|
| 多店舗展開型 | 売上高の伸び、営業利益率、**フリーCFと有利子負債÷純資産**（出店を借入で回していないか） |
| ストック型 | 売上高の伸びと営業利益率の**両方**（解約が増えると伸びだけ落ちる）、売上総利益率 |
| 営業人員依存型 | 総人員あたり営業利益（増員が利益になっているか）、売上総利益率 |

どの型でも、**伸びと採算を1組**で見る。売上だけ伸びて利益率が落ちていれば、
成長は買っているだけかもしれない。

小型株を狙う前提では、次の3つはどの型でも1度は確かめる。

- **時価総額** … 小さいほど倍率は伸びる。同じ事業で1桁小さい競合がいないか
- **ROE** … 10倍になった会社とならなかった会社をいちばんよく見分ける。
  ただしROAと自己資本比率で、借入で嵩上げしていないかを必ず確かめる
- **PEGレシオ** … リンチの目安で1.0が適正、0.5未満で割安。
  PERが高くても成長が速ければ割高とは限らない

### 4. 「気をつける点」に必ず書くもの

実データで踏んだもの。当てはまるときは書く。

- **「従業員一人当たり営業利益」の分母は正社員だけ。** 平均臨時雇用人員は
  入っていない。パートの比率が高い会社ほど良く見える。フィットイージーは
  正社員65人・臨時211人（総人員の76%）で、この指標は35.6百万だが、
  総人員276人で割ると8.4百万になり、臨時7人のFFJ（7.0百万）とほぼ並ぶ。
  **一度これを「FFJの5倍」と書いて間違えた。** 従業員数と平均臨時雇用人員の
  2枚を必ず一緒に見る
- **競合が同じ土俵か。** 持株会社が競合に入っていると営業利益率が跳ねる
  （フィットイージーの競合カーブスHは84%。フランチャイズのロイヤリティ収入が
  中心の持株会社なので、直営店を持つ会社と並べても意味がない）
- **上場したばかりで年数が足りない。** 年平均成長率が2〜3期から出ていると、
  1回の跳ねがそのまま倍率になる
- **株式分割でEPSが不連続。** フィットイージーは1:1,000分割をまたいで
  2021年48,189円→2022年3.68円。年平均成長率は成長性を表さない
- **PEGが負。** EPSが減っている会社では意味を持たない
- **決算期が競合とずれている。** 直近同士を比べているつもりが1年ずれる
- **同じ値が2期に入っていることがある。** フィットイージーは2024-02-01と
  2025-01-31の純資産・総資産・当期純利益が同値。1期ぶん重複している

### 全部の指標に目を通す

**17項目ある。** 上から11項目だけ見て書くと、下のほうにある平均臨時雇用人員を
見落として、上のような読み違いをする。`--brief` の出力を最後まで通す。

### 4-2. 専門的に書くために

素人の書き方と分かれるのはここ。**単独の指標を褒めない。**

| 素人の書き方 | 専門的な書き方 |
|---|---|
| 営業利益率23.8%は高い | 営業利益率23.8%は業種中央値5.9%の4倍で上位14%。10倍になった会社の上場2年目の中央値9.5%も大きく上回る。ただし**続くかは別なので、原価の構成で裏を取る** |
| 売上が年45%伸びている | 売上は年45%伸びているが**営業利益率は24.5%→23.8%に落ちている**。出店の先行費用か、値引きかを原価の構成で確かめる |
| ROE34.5%と高い | ROE34.5%に対しROA15.2%・自己資本比率58.4%なので、**借入で嵩上げした高ROEではない** |
| 財務は健全 | 現金3,274百万が有利子負債312百万を上回り実質無借金。**ただしフリーCFは-316百万で、出店を手元資金で食っている** |

**必ず1つは「上場N年目に10倍になった会社と比べてどうか」を書く。** 狙っているのは
小型の成長株なので、同業の平均と比べるより、**実際に10倍になった会社が
同じ時期に何をしていたか**のほうが判断に効く。

### どの指標に見分ける力があるか（実測）

2011〜2016年に上場した会社に限り（経過年数を揃えないと「10倍組」対
「まだ時間が経っていない組」を比べることになる）、上場3年目の中央値。

| | 10倍以上 | 3〜10倍 | 2倍未満 | |
|---|---|---|---|---|
| **ROE** | 18.2% | 13.7% | 9.7% | 見分けられる。**いちばん強い** |
| **営業利益率** | 12.1% | 6.3% | 5.0% | 見分けられる |
| **売上高** | 7,084百万 | 6,083百万 | 11,251百万 | **小さいほうが10倍になっている** |
| 利益の質 | 0.71倍 | 0.89倍 | 1.34倍 | **逆。10倍組のほうが低い** |

**利益の質（営業CF÷営業利益）を成長株の良し悪しの判定に使わない。**
伸びている会社ほど運転資金と設備で現金が出るので、低いのが普通。
「1.0を割っているから危ない」と書くと逆になる。一度これを書いて間違えた。
資金繰りが持つかは有利子負債と現金のほうで見る。

数字が良いほうに揃っているときほど**どこが劣っているか**を探すが、
**見分ける力の無い指標で劣っていても、それは弱点ではない。**
`--diagnose` は見分けられない指標に印を出すので、そこは根拠にしない。

### 5. 守ること

- **グラフに出ていないことを書かない。** ここは読み方であって、
  新しいデータを持ち込む場所ではない
- 数字は `metric_compare_dump.py` の出力と一致させる
- 良い点と悪い点を両方書く。3つとも良い話なら見どころの選び方を疑う
- 判定（買う・売る）は書かない。それは総括（`holding-profile`）の仕事

```bash

```
