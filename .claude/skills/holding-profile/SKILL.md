# 保有銘柄の読み解きと総括を書く

`data/meta/business_profile.tsv` に1銘柄1行。画面では3つに分かれて出る。

| 出す場所 | 中身 |
|---|---|
| 「事業の内容」カードの先頭 | 収益の源泉 / 稼ぎ方の型 / 競合との違い / 事業の弱み |
| 「役員の状況」カードの先頭 | 経営陣の経歴 / 経歴と事業の噛み合い / 経営陣の懸念 |
| 独立した「総括」カード | 判定 / 買う理由 / 持ち続ける条件 / 降りる条件 / 株価水準 |

対象は保有銘柄のみ（自分・テンバガーX・お気に入り）。全銘柄には広げない。

## いちばん大事なこと

**書き終えたら「これを読んで、自分はこの株を買うか・持ち続けるか」を自問する。**
答えられないなら、それは事業の解説であって投資の判断材料になっていない。

解説で終わっている文章にはこういう特徴がある。

- 良い点しか書いていない
- 「〜が強み」で終わり、その強みが崩れる条件が書いていない
- 株価とPERに触れていない（いくらでも買っていいことになってしまう）
- **経営陣が自社株を売っていても書いていない**

最後のものが致命的。長期で持つかどうかを決めるのに、創業者が降り始めた事実を
書かない読み解きは役に立たない。

## 手順

### 1. 判断に要る数字を全部出す

```bash
python collectors/holding_judgment_dump.py 212A            # 1銘柄を詳しく
python collectors/holding_judgment_dump.py 6574 8037 369A --brief   # 何社もまとめて
```

テンバガー条件・売上と利益の推移・株価とPERと高値からの位置・ロックアップ・
拠点あたりの採算・原価の構成・大株主と役員の持株推移・上場時の諸元・
保有比率が、まとめて出る。**これを見ずに書かない。**

`--brief` は1銘柄10行で、業績の推移・株価とPER・満たさない条件・拠点あたり・
**役員の持株が何%動いたか**だけを出す。何社も続けて書くときはこちら。
数字が引っかかった銘柄だけ `--brief` なしで詳しく見る。

### 2. 有報の本文を読む

```bash
python collectors/holding_profile_dump.py 212A
```

事業の内容、役員の状況、競合の事業の内容が出る。

### 3. 使えるデータと、使えないデータ

| データ | 状態 |
|---|---|
| 有価証券報告書（XBRLと本文） | 使える。44,000件 |
| 期中の報告書（四半期・半期） | 保有銘柄のみ使える |
| 株価・出来高・PER | 使える（yfinance） |
| 上場時の諸元（社長株%・VC%・初値など） | 使える（`all_companies.tsv`） |
| 適時開示（TDnet） | **保有32銘柄ぶんは取得済み。** 本文PDFも読める |
| 大量保有報告書 | 全銘柄使える。ただし**直近5年ぶんだけ** |
| 月次開示 | 収集していない |

適時開示は必ず見る。ここに、有報だけでは分からないことが出ている。

```bash
python collectors/disclosure_check.py            # 保有銘柄すべて
python collectors/disclosure_check.py 212A --months 6
```

業績予想の修正・配当・大株主の異動・組織資本・悪材料・役員の異動だけを拾う。
決算短信は毎期出るので除いてある。

`data/output/tdnet/disclosures_<IPO年>.tsv` はファイル名がIPO年で、中身は
その年に上場した企業の開示。開示日ではない。

### 3-2. 「なぜ」まで確かめる

一覧に出るのはタイトルだけで、上方か下方か、なぜ売ったのかは本文にしかない。
**タイトルから理由を推測して書かない。** 実際にそれで一度間違えている（後述）。

```bash
python collectors/disclosure_pdf.py 5843 --match 業績予想 --grep 修正の理由
python collectors/disclosure_pdf.py 212A --match 売出 --grep 流通株式 目的
```

大株主の売買は大量保有報告書のほうが細かい。5%超を持つ人は保有割合が1%動く
たびに5営業日以内に出すので、**期末の断面ではなく日付単位**で追え、
提出事由と保有目的が付いてくる。画面の「5%超の株主の売買」に出ている。

```bash
python collectors/large_holding_collector.py --codes 212A
```

**なぜ売買したかは「なぜ」の欄に出ている。** 書類の「増減の内訳」に
1件ずつ日本語で書かれているものを型に落としたもので、売出し・IPOの売出し・
追加売出し・立会外分売・公開買付・自己株買い・株式分割・関係者間で移動など。
単価と市場内外も出る。ただし**内訳を書かない提出者がいて、埋まるのは約半分**。
「不明」は「書類に書かれていない」という意味で、推測で埋めない。

なお**保有目的は届出の定型文**（「安定株主として長期保有」など）で、
売った理由には使えない。売出しの背景など会社側の説明は適時開示の本文にある。

### 4. TSVに1行足す

| 列 | 書くこと |
|---|---|
| コード / 銘柄名 | |
| 収益の源泉 | 誰に何を売って、どこで利益が出るか。**売上構成比が有報にあれば必ず入れる** |
| 稼ぎ方の型 | ストック型 / 多店舗展開型 / 営業人員依存型 |
| 競合との違い | 競合を名指しして具体的に。1拠点あたりや原価率の数字を添える |
| 事業の弱み | 事業として崩れうる点。競合が設定されていないなら比較できていないと書く |
| 経営陣の経歴 | 社長と、事業に効いている役員の前職。年数まで |
| 経歴と事業の噛み合い | **その経歴がどの数字に出ているか** |
| 経営陣の懸念 | **持株の増減を必ず見る。** 売っていれば株数と時期を書く。同族集中・兼務過多・承継もここ |
| 判定 | 次の5つから1つ（下記） |
| 買う理由 | なぜ持つ価値があるか。数字で |
| 持ち続ける条件 | **何が続いていれば持つのか。** 確認できる指標で書く |
| 降りる条件 | **何が起きたら売るのか。** 数字とイベントで書く |
| 株価水準 | 直近PER、公開価格時PER、高値からの位置、時価総額 |
| 見たデータ | 使ったもの。見ていないもの（直近の適時開示など）も書く |
| 出所報告日 / 作成日 | |

### 判定の5段階

| 判定 | 意味 |
|---|---|
| 買い増し検討 | 事業も経営陣も良く、株価も高くない |
| 継続保有 | 持ち続ける理由がある。新規に買う水準ではない |
| 様子見 | 良い面と悪い面が拮抗。次の決算などを待つ |
| 縮小検討 | 崩れの兆候がある。比率を下げることを考える |
| 判断保留 | データが足りない。何が足りないかを書く |

**判定は忖度しない。** 保有している銘柄でも、経営陣が売っていて減益なら
そう書く。持っているから良く書く読み解きには価値がない。

### 5. 書き方の約束

- 1項目2〜3文。散文で長く書かない
- 数字は画面に出ているものと一致させる。将来ずれる細かい値は幅で書く
- 分からないことは書かない。推測を断定で書かない
- 良い点と悪い点を必ず両方書く
- **降りる条件は、この画面で確かめられる形で書く。** 「1店舗あたり利益が競合
  中央値の2倍を割る」は拠点あたりの採算カードで見える。「FC加盟店の退店が
  出始める」は今のデータでは見えないので、そう書くなら見えないことも添える
- 株価水準には**ポートフォリオでの比率**を入れる。個別に良い銘柄でも、1銘柄で
  5割を占めていれば判断は変わる。**どのポートフォリオの比率かを書く。**
  自分が持っていない銘柄なら「テンバガーXでは3.8%（自分は未保有）」のように書く

### 持株の増減を書く前に、分割を疑う

役員や大株主の株数が期のあいだで2倍・半分に動いていたら、**まず株式分割の
調整がずれていないかを確かめる。** 実際にGENDAで、片岡尚の持株が
21,091,200→11,122,800→25,600,600株と乱高下しているように見え、それを
「経営陣が売り買いしている」と書いてしまった。調べると分割調整のずれで、
実際は21,091,200→22,245,600→25,600,600と増やし続けていた。

```bash
python -c "import yfinance; print(yfinance.Ticker('9166.T').splits)"
```

`holdings_service` は役員の基準日（提出日か期末か）を銘柄ごとに自動で選ぶが、
それでも合わないことがある。**2倍・半分の動きは、売買よりも分割を先に疑う。**

### 売ったと書く前に、なぜ売ったかを読む

株数が減っていても、それが「創業者が降り始めた」とは限らない。
**フィットイージー(212A)で一度これを間違えた。** 國江仙嗣が3,242,100→1,427,200株と
半分以下にしているのを見て「上場2年目に個人保有株の56%を売却」と書いたが、
開示の本文を読むと**東証プライムの上場基準「流通株式比率35%」を満たすための
売出し**だと明記されていた。議決権は68.90%→55.25%で支配は維持、
ロックアップも掛かっている。意味がまるで違う。

株数が減っていたら、順に確かめる。

1. 分割調整のずれではないか
2. **関係者間の移動ではないか。** 創業者が資産管理会社に持ち替えると、
   個人の株数だけが減る。画面では「関係者間で移動」と出る（3300がその例で、
   清水剛→TSコーポレーションに1,823,636株）
3. 大量保有報告書の「なぜ」に何と書いてあるか（画面の「5%超の売買」タブ）
4. その時期の適時開示の本文に理由が書かれていないか（`disclosure_pdf.py`）

4まで見て理由が分からなければ、**分からないと書く。** 推測を断定で書かない。

### 6. ついでに拠点数を確かめる

有報を読んでいるので、拠点数の抽出が合っているかも見る。誤っていれば
`data/meta/facility_override.tsv` に書く。判定の癖は `facility-count` スキル。

### 7. 確認する

```bash
python -m visualizer.app
python scripts/verify_visualizer_deep.py
```

3箇所（事業カード・役員カード・総括カード）に出ることと、スマホ幅で
崩れないことを見る。

## 参考になる書き方

フィットイージー(212A)の総括を見るのが早い。書いた時点で

- 1店舗あたり利益は競合中央値の3.0倍、原価の79%が仕入で社長は内装35年
- 創業社長は181万株を放出しているが、理由はプライム市場の流通株式比率35%の
  充足で、議決権は55%を維持している（**株数の減少と、降り始めたことは別**）
- 開発売上62.6%は出店時の一時収益で、ストックではない
- PER32倍は公開価格時20.8倍から切り上がり、高値から89%の位置

という良い面と悪い面が同時に立っている。**どちらか片方だけを書かない。**

## やってはいけないこと

- 全銘柄に広げる（トークンが持たない。保有銘柄以外は将来 OpenRouter の無料モデル）
- 抽出した数字と混ぜる。画面では「AIによる解釈」のバッジで区別している
- 判定を書かずに解説だけ置く
- 経営陣の持株の増減を見ずに「長期保有」と書く
- **持株が減ったのを見て、理由を確かめずに「売り抜けた」と書く**
