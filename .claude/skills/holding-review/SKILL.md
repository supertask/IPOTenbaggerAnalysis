# 保有銘柄の読み解きと総括を書く

画面に出るAIの解釈は**すべてこのスキルで書く。** 書き先のTSVは2つ。

| TSV | 粒度 | 画面のどこ |
|---|---|---|
| `data/meta/business_profile.tsv` | **1銘柄1行** | 事業の内容カード / 役員の状況カード / 財務指標の比較 / 総括カード |
| `data/meta/disclosure_reading.tsv` | **1開示1行**（URLがキー） | 「持株の推移」→「5%超の売買」タブの理由の下 |

粒度が違うのでTSVは分けているが、**読む材料が重なるので手順は1つにしてある。**
同じPDFを2回読まない。開示を読むのは1回にして、総括と要約を同じときに書く。

## business_profile.tsv の列と、出る場所

| 出す場所 | 列 |
|---|---|
| 「事業の内容」カードの先頭 | 収益の源泉 / 稼ぎ方の型 / 競合との違い / 事業の弱み |
| 「役員の状況」カードの先頭 | 経営陣の経歴 / 経歴と事業の噛み合い / 経営陣の懸念 |
| ページ下部「財務指標の比較」の見出し直下 | 見どころ / 競合との差 / 数字の注意 |
| 独立した「総括」カード | 判定 / 買う理由 / 持ち続ける条件 / 降りる条件 / 株価水準 |

対象は保有銘柄のみ（自分・テンバガーX・お気に入り）。全銘柄には広げない。

## どこを書き直すか

全部を毎回書き直さない。**更新の理由に応じて書き直す列を決める。**

| きっかけ | 書き直す列 |
|---|---|
| 決算が出た（四半期） | 見どころ / 競合との差 / 数字の注意 / 株価水準 / 判定 |
| 有報が出た（年1回） | 全部 |
| 大株主・役員が動いた | 経営陣の懸念 / 降りる条件 / 判定 ＋ **開示の要約** |
| 適時開示で重い材料が出た | 判定 / 降りる条件 / 見たデータ ＋ **開示の要約** |
| 銘柄を新しく足した | 全部 |

**書き直した列だけ更新し、作成日を入れ替える。** 触っていない列を
消したり書き換えたりしない。

以前は財務指標の読み方だけ別のスキル・別のTSVにしていたが、同じ材料
（有報・業績・競合）を2回読むことになり、株価水準の欄で内容も重複していた。
1つにまとめてある。

## いちばん大事なこと

**書き終えたら「これを読んで、自分はこの株を買うか・持ち続けるか」を自問する。**
答えられないなら、それは事業の解説であって投資の判断材料になっていない。

解説で終わっている文章にはこういう特徴がある。

- 良い点しか書いていない
- 「〜が強み」で終わり、その強みが崩れる条件が書いていない
- 株価とPERに触れていない（いくらでも買っていいことになってしまう）
- **経営陣が自社株を売っていても書いていない**

最後のものが致命的。長期で持つかどうかを決めるのに、創業者が降り始めた事実を
書かない読み解きは役に立たない。

## 手順

### 0. 競合を取り直す（書き始める前に、まとめて1回）

```bash
python collectors/refresh_competitors.py            # 保有銘柄ぜんぶ
```

比較企業は四季報オンラインの自動選定で、**向こうが黙って入れ替える。**
収集は一度取れたら二度と見に行かないので、放っておくと上場直後の顔ぶれのまま
古くなる。2026年8月に保有32銘柄を取り直したら**16銘柄で変わった**
（350Aはレジル・ラクスル → グリムス・Eチェンジ、212AはFFJ → セントラルスポーツ）。

古い競合のまま書くと、画面に出ていない相手と比べた文章が残る。
「競合4社で最小」のような順位は特に効くので、**取り直してから書く。**

前回の取得から80日たったものだけを取りに行くので、続けて回しても無駄がない
（初回は32銘柄で15分ほど、2回目からは数分）。全部取り直すなら `--force`。

**競合との比較は、順位や倍率ではなく絶対値で条件を書く。**
「1店舗あたり利益が競合中央値の2倍を保っていること」と書くと、四季報が
比較企業を入れ替えたときに条件のほうが動いてしまう。「1店舗あたり9百万」と書く。

四季報の選定そのものが業態とずれていて、取り直しても直らないときは
`data/meta/competitor_override.tsv` に人が書く（使い方はファイルの中）。
GENDAに技術承継機構・SHIFT、リクルートにソニーG・ソフトバンクGが出るような、
規模や成長の型が似ているだけで事業が違う組み合わせがこれに当たる。

### 1. 判断に要る数字を全部出す

```bash
python collectors/holding_judgment_dump.py 212A            # 1銘柄を詳しく
python collectors/holding_judgment_dump.py 6574 8037 369A --brief   # 何社もまとめて
```

テンバガー条件・売上と利益の推移・株価とPERと高値からの位置・ロックアップ・
拠点あたりの採算・原価の構成・大株主と役員の持株推移・上場時の諸元・
保有比率が、まとめて出る。**これを見ずに書かない。**

`--brief` は1銘柄10行で、業績の推移・株価とPER・満たさない条件・拠点あたり・
**役員の持株が何%動いたか**だけを出す。何社も続けて書くときはこちら。
数字が引っかかった銘柄だけ `--brief` なしで詳しく見る。

### 2. 有報の本文を読む

```bash
python collectors/holding_profile_dump.py 212A
```

事業の内容、役員の状況、競合の事業の内容が出る。

### 2-2. 財務指標を、10倍になった会社と並べて見る

```bash
python collectors/metric_compare_dump.py 212A --brief --diagnose
```

**`--diagnose` を付けずに書かない。** 指標を縦に並べただけでは
「売上が伸びている」で止まる。付けると次の4つが足される。

| 足されるもの | 何が分かるか |
|---|---|
| **所見** | 組み合わせでしか読めないもの。「売上↑なのに利益率↓」「ROE↑なのにROA→（借入で嵩上げ）」を機械で当てる |
| **同じ業種の中央値** | 営業利益率23.8%が高いのかは業種で変わる。上位何%かも出る |
| **何倍になったかで分けた比較** | 上場N年目に、10倍以上／3〜10倍／2倍未満だった会社がそれぞれどうだったか |
| **データの欠け・異常** | 比較できていない指標、同じ値が2期続いている（期の重複） |

#### どの指標に見分ける力があるか（実測）

2017年までに上場した会社（経過年数を揃えないと「10倍組」対「まだ時間が
経っていない組」になる）の直近の中央値。

| | 10倍以上 | 3〜10倍 | 2倍未満 | |
|---|---|---|---|---|
| **ROE** | 15.0% | 11.3% | 6.4% | **いちばん強い** |
| **総人員あたり営業利益** | 280万円 | 130万円 | 97万円 | 2.9倍の差 |
| **営業利益率** | 8.6% | 5.6% | 3.5% | 見分けられる |
| **有利子負債÷純資産** | 0.14倍 | 0.48倍 | 0.28倍 | 借金が少ないほうが10倍 |
| **配当性向** | 36.7% | 34.2% | 51.8% | 配当を出さないほうが10倍 |
| PER | 16.7倍 | 16.3倍 | 16.2倍 | **見分けない** |
| 利益の質 | 0.91倍 | 0.98倍 | 0.91倍 | **見分けない** |
| ネットキャッシュ比率 | 0.20倍 | 0.24倍 | 0.37倍 | **逆** |
| 希薄化率 | 0.42% | 1.09% | 0.45% | 見分けない |

**次の3つを判定の根拠にしない。**

- **利益の質** … 伸びている会社ほど運転資金と設備で現金が出るので低いのが普通。
  「1.0を割っているから危ない」と書くと逆になる。一度これを書いて間違えた
- **PER** … 成長率を見ていないので単体では効かない。PEGで見る
- **ネットキャッシュ比率** … 現金を溜めている会社より使って伸びる会社が上がる。
  割安株を買うための指標

**株価から作る指標（時価総額・PSR・PER）は、現在値で10倍組と比べると逆に出る。**
10倍になった結果として大きいだけ。自社の絶対水準で書く。

`--diagnose` は見分ける力の無い指標に印を出す。**そこで劣っていても弱点ではない。**

#### 指標そのものの説明は書かない

各グラフの「?」に、定義・計算式・**いくつなら良いか（全社の中央値と上位25%）**・
どこを見るか・罠・誰が推しているか、が全39指標ぶん入っている
（`visualizer/metric_help.py`）。**ここと同じことを書かない。**
TSVに書くのは「この銘柄はどうなのか」だけ。

#### 本が何と言っているか

`references/investor-books.md` に、本4冊（リンチ『株で勝つ』・清原達郎
『我が投資術』・テンバガー投資家X『トイレスマホで「無限10倍株」』・
DAIBOUCHOU『成長投資枠で一億円』）と媒体記事1件（エミン・ユルマズの
10倍株の4条件）から、指標にまつわる箇所を抜いてある。**本文は非公開の
別リポジトリ `../BookScraper/book_texts/stock_investment/` にあり、
ここには置かない。** MCPの `search_books` で原文を検索できる。

**「降りる条件」を書くときは、まずDAIBOUCHOUを見る。**
数字で売り時を書いているのはこの本だけで、しかも**いまのデータで
そのまま計算できる。**

| 規則 | どこで確かめるか |
|---|---|
| **四半期で2〜3期連続、前年同期比を割ったら売る** | `tanshin_xbrl` の四半期実績 |
| **営業利益の進捗率が1Qで25%超・2Q累計で50%超なら上方修正の可能性** | 同上＋会社予想 |
| **20%成長が10%に鈍化したら売る**（説明がつくなら継続してよい） | 業績のグラフ |
| **PER8倍で買ったものが20〜30倍になったら利確**（成長が続くなら継続） | PERのグラフ |
| 公募増資・MSワラントは発行済株式数を増やして希薄化させる | 発行済株式数・適時開示 |

**PERは5人とも見るが、絶対値で切るかどうかが割れる。**
リンチは「絶対値で切るのは賛成しかねる」と明言して型ごとの水準を使い
（急成長株14〜20倍、優良株10〜14倍）、清原はネットキャッシュで補正
（キャッシュニュートラルPER）。一方でX（40倍以下・理想20倍以下）、
清原（10倍以下は総じて割安）、DAIBOUCHOU（10倍前後）は絶対値を出す。
画面のPEGレシオとキャッシュニュートラルPERはリンチ・清原側の考え方。

時価総額の小ささは5人とも見ている（いちばん重なる）。
**営業利益率とPBRは「見なくていい」と書いている人がいる。**

**ROEとROAは、本4冊のうちDAIBOUCHOUにしか出てこない**
（他3冊は本文検索で0回。DAIBOUCHOUはROE最低8%・目安15%＋PER10倍前後）。
実測でいちばん見分けたので画面には置いてあるが、**「本が推している」と
書くならDAIBOUCHOUを出典にすること。**

**上場からの年数では、本どうしが正面から食い違う。**
X「上場1年以内が主戦場」・エミン「5年以内」に対し、清原は「VCが厚化粧
させた時期に出てくる」、リンチは「新規上場の4つのうち3つは失望させられる」。
このサイトはX／エミン側の前提に立っているので、**反対側の言い分がある
ことを承知したうえで書く。**

本と実測が食い違ったら**両方書く**。たとえばテンバガー投資家Xは営業利益率を
重視しないと書いているが、実測では10倍組と2倍未満組をはっきり見分ける。
これは「買う時点で利益率が高い銘柄は既に高い」と「10倍になった会社は
結果として利益率が高かった」の違いで、矛盾ではない。潰さずに書く。

### 3. 使えるデータと、使えないデータ

| データ | 状態 |
|---|---|
| 有価証券報告書（XBRLと本文） | 使える。44,000件 |
| 期中の報告書（四半期・半期） | 保有銘柄のみ使える |
| 株価・出来高・PER | 使える（yfinance） |
| 上場時の諸元（社長株%・VC%・初値など） | 使える（`all_companies.tsv`） |
| 適時開示（TDnet） | **保有32銘柄ぶんは取得済み。** 本文PDFも読める |
| 大量保有報告書 | 全銘柄使える。ただし**直近5年ぶんだけ** |
| 月次開示 | 収集していない |

適時開示は必ず見る。ここに、有報だけでは分からないことが出ている。

```bash
python collectors/disclosure_check.py            # 保有銘柄すべて
python collectors/disclosure_check.py 212A --months 6
```

業績予想の修正・配当・大株主の異動・組織資本・悪材料・役員の異動だけを拾う。
決算短信は毎期出るので除いてある。

`data/output/tdnet/disclosures_<IPO年>.tsv` はファイル名がIPO年で、中身は
その年に上場した企業の開示。開示日ではない。

### 3-2. 「なぜ」まで確かめる

一覧に出るのはタイトルだけで、上方か下方か、なぜ売ったのかは本文にしかない。
**タイトルから理由を推測して書かない。** 実際にそれで一度間違えている（後述）。

```bash
python collectors/disclosure_pdf.py 5843 --match 業績予想 --grep 修正の理由
python collectors/disclosure_pdf.py 212A --match 売出 --grep 流通株式 目的
```

大株主の売買は大量保有報告書のほうが細かい。5%超を持つ人は保有割合が1%動く
たびに5営業日以内に出すので、**期末の断面ではなく日付単位**で追え、
提出事由と保有目的が付いてくる。画面の「5%超の株主の売買」に出ている。

```bash
python collectors/large_holding_collector.py --codes 212A
```

**なぜ売買したかは「なぜ」の欄に出ている。** 書類の「増減の内訳」に
1件ずつ日本語で書かれているものを型に落としたもので、売出し・IPOの売出し・
追加売出し・立会外分売・公開買付・自己株買い・株式分割・関係者間で移動など。
単価と市場内外も出る。ただし**内訳を書かない提出者がいて、埋まるのは約半分**。
「不明」は「書類に書かれていない」という意味で、推測で埋めない。

タグの下の黒い文は**開示PDFの本文そのもの**（`disclosure_summary.py`）。
会社ごとの事情はここにしかない。総括に書くならこれを読む。

なお**保有目的は届出の定型文**（「安定株主として長期保有」など）で、
売った理由には使えない。売出しの背景など会社側の説明は適時開示の本文にある。

### 3-3. 開示を読んだついでに、要約も書く

いま読んだ開示PDFは、**画面の「5%超の売買」タブにも出す。**
書き先が `data/meta/disclosure_reading.tsv`（1開示1行、URLがキー）と別なだけで、
読む材料は同じ。**総括を書くときに一緒に書く。あとで別に読み直さない。**

```bash
python collectors/disclosure_summary.py --dump --todo   # まだ書いていないもの
```

手順の詳細は **`references/disclosure-summary.md`**。要点だけ:

- 1〜2文、60〜110字。①何をしたか ②なぜか ③株主にとって何を意味するか
- **`株主にとって` も同じときに付ける**（好材料／悪材料／中立／判断できない）。
  **これは中身の良し悪しで、株価の予測ではない。** 本文の数字だけで決め、
  **その後の株価は見ない**（見ると後知恵になる）。基準は `references/disclosure-summary.md`
- **書いてあることだけ書く。**「〜の可能性がある」を使いたくなったら、
  それは書いていないということ
- 月次の進捗報告（自己株式の取得状況など）は、**理由ではなく実績を書く。**
  以前は「理由が載っていないから書かない」としていたが、実際に読むと
  進捗そのものが材料になっていた。7320は自己株式の取得枠を設定したのに
  **4か月連続で0株**で、書かないとこれが埋もれる。4480は月92,300株→3,000株と
  ペースが落ちていた。理由は元の決議の開示にあるので、そちらを参照する

### 4. TSVに1行足す

| 列 | 書くこと |
|---|---|
| コード / 銘柄名 | |
| 収益の源泉 | 誰に何を売って、どこで利益が出るか。**売上構成比が有報にあれば必ず入れる** |
| 稼ぎ方の型 | ストック型 / 多店舗展開型 / 営業人員依存型 |
| 競合との違い | 競合を名指しして具体的に。1拠点あたりや原価率の数字を添える |
| 事業の弱み | 事業として崩れうる点。競合が設定されていないなら比較できていないと書く |
| 経営陣の経歴 | 社長と、事業に効いている役員の前職。年数まで |
| 経歴と事業の噛み合い | **その経歴がどの数字に出ているか** |
| 経営陣の懸念 | **持株の増減を必ず見る。** 売っていれば株数と時期を書く。同族集中・兼務過多・承継もここ |
| 見どころ | 38枚のグラフのうち、まずどれを見るか。3つまで。なぜそれを見るのかを1文で（下記） |
| 競合との差 | 競合と、**10倍以上／2倍未満に終わった組**と並べて何が違うか。数字で |
| 数字の注意 | そのまま読むと誤るところ。分母・分割・期の重複・土俵の違う競合 |
| 判定 | 次の5つから1つ（下記） |
| 買う理由 | なぜ持つ価値があるか。数字で |
| 持ち続ける条件 | **何が続いていれば持つのか。** 確認できる指標で書く |
| 降りる条件 | **何が起きたら売るのか。** 数字とイベントで書く。**会社の予想が下を向いたら書く**（下記） |
| 株価水準 | 直近PER、公開価格時PER、高値からの位置、時価総額 |
| 見たデータ | 使ったもの。見ていないもの（直近の適時開示など）も書く |
| 出所報告日 / 作成日 | |

### 「見どころ」の選び方

**稼ぎ方の型で変わる。** その銘柄の型（同じTSVの列）を先に決めてから選ぶ。

| 型 | まず見るもの |
|---|---|
| 多店舗展開型 | 売上高の伸びと営業利益率、**フリーCFと有利子負債÷純資産**（出店を借入で回していないか） |
| ストック型 | 売上高の伸びと営業利益率の**両方**（解約が増えると伸びだけ落ちる）、売上総利益率 |
| 営業人員依存型 | 総人員あたり営業利益（増員が利益になっているか）、売上総利益率 |

どの型でも**伸びと採算を1組**で見る。売上だけ伸びて利益率が落ちていれば、
成長を買っているだけかもしれない。

小型株を狙う前提では、次の4つはどの型でも1度は確かめる。

- **時価総額** … Xは「テンバガーの約7割は最安値時点で500億円未満」
- **ROE** … 10倍組15.0%・2倍未満組6.4%でいちばんよく見分ける。
  ただしROAと自己資本比率で、借入で嵩上げしていないかを必ず確かめる
- **PEGレシオ** … リンチの目安で1.0が適正、0.5未満で割安
- **有利子負債と現金** … リンチ「現金が一〇億ドル、借金が五億ドルあって云々
  という程度の、小学校四年生くらいの算数の知識で十分」

### 素人の書き方と専門的な書き方

**単独の指標を褒めない。**

| 素人 | 専門的 |
|---|---|
| 営業利益率23.8%は高い | 業種中央値5.9%の4倍で上位14%。10倍組の8.6%も上回る。ただし続くかは別なので原価の構成で裏を取る |
| 売上が年45%伸びている | 売上は年45%伸びているが**営業利益率は24.5%→23.8%に落ちている**。出店の先行費用か値引きかを確かめる |
| ROE34.5%と高い | ROE34.5%に対しROA15.2%・自己資本比率58.4%なので、**借入で嵩上げした高ROEではない** |
| 財務は健全 | 現金32.7億が有利子負債3.1億を上回り実質無借金。**ただしフリーCFは-3.2億で出店を手元資金で食っている** |

**必ず1つは「10倍になった会社と比べてどうか」を書く。**
数字が良いほうに揃っているときほど、どこが劣っているかを探す。
ただし**見分ける力の無い指標（PER・利益の質・ネットキャッシュ比率・希薄化率）で
劣っていても、それは弱点ではない。**

### 判定の5段階

| 判定 | 意味 |
|---|---|
| 買い増し検討 | 事業も経営陣も良く、株価も高くない |
| 継続保有 | 持ち続ける理由がある。新規に買う水準ではない |
| 様子見 | 良い面と悪い面が拮抗。次の決算などを待つ |
| 縮小検討 | 崩れの兆候がある。比率を下げることを考える |
| 判断保留 | データが足りない。何が足りないかを書く |

**判定は忖度しない。** 保有している銘柄でも、経営陣が売っていて減益なら
そう書く。持っているから良く書く読み解きには価値がない。

### 5. 書き方の約束

- 1項目2〜3文。散文で長く書かない
- 数字は画面に出ているものと一致させる。将来ずれる細かい値は幅で書く
- 分からないことは書かない。推測を断定で書かない
- 良い点と悪い点を必ず両方書く
### 会社自身の業績予想を必ず見る

詳細ページの**「会社の業績予想の推移」**カード（決算短信のXBRL）。
**有報には実績しか無い。見通しはここにしか無い。**

**実績より早く出る。**「利益率が3%を割ったとき」のような実績の条件は
起きてから分かるが、会社が見通しを下げるほうが先に見える。

**カードには3つの数字があり、重みが違う。** 混ぜないこと。

| 見るもの | 何か | どう効くか |
|---|---|---|
| **直近** | 新年度の期初予想が、前年の期初から何%動いたか | **前年割れがいちばん鋭い。** 保有22銘柄で前年割れの4社は全部が最高値の61%以下、うち3社は半分を切っていた |
| **期初の伸び** | それの年ごとの中央値 | **良さの物差し。** +35%以上の8社が最高値の86%を保っていた |
| **期中の修正** | 期初に置いた数字を期の途中で上げ下げしたか | 上方修正の回数は効かない。**未達が毎期続くか**だけ見る |

| 銘柄 | 営業利益 | 読み |
|---|---|---|
| 5592 | +41%/年（直近+41%・上2/下0・未達0） | 見通しを上げ続けている |
| 3496 | +44%/年（直近+26%・8期で未達1） | 同上。未達1回は無視してよい |
| 9158 | **+16%/年だが直近 −31%**（純利益は **−62%**） | **新年度の見通しを3割下げた** |
| 7388 | **+6%/年・直近 −46%・未達3/5期** | **毎期外し続けている** |

**中央値だけ見ると9158を見落とす。** +16%/年は悪くない数字に見えるが、
実際は期初を55.0億→38.0億に下げている。**これは期中の修正ではないので
「下方修正」にも出ない。** 必ず「直近」を見る。

書き方。

- **直近が前年割れ**なら「降りる条件」に書き、何億→何億かを添える
  （例: 「2026-06-04の短信で新年度の営業利益予想を55.0億→38.0億（−31%）に
  置いた。次の期初でも前年割れなら降りる」）
- **期初の伸びが+35%以上で続いている**なら「持ち続ける条件」に入れる
- **未達が毎期続く**なら降りる材料。1回は無視してよい（3496は8期で1回だが92%を保っている）
- 売上の予想だけ上がって利益の予想が下がっていたら、それは採算の悪化。
  **利益のほうを採る**（9158は売上だけ直近+11%で、利益3行が前年割れ）

**上方修正を買いの材料にしない。** 修正の前後60営業日を76件測ると、
上方修正は発表前に株価が+12%動いていて発表後は+5%しかない（後追い）。
下方修正は発表前が−1.5%で発表後に−8%（まだ8割方が残っている）。
**動く材料は下向きのほうだけ。**

MCPからは `tanshin_xbrl` の「予想の推移」で同じものが取れる。

- **降りる条件は、この画面で確かめられる形で書く。** 「1店舗あたり利益が競合
  中央値の2倍を割る」は拠点あたりの採算カードで見える。「FC加盟店の退店が
  出始める」は今のデータでは見えないので、そう書くなら見えないことも添える
- 株価水準には**ポートフォリオでの比率**を入れる。個別に良い銘柄でも、1銘柄で
  5割を占めていれば判断は変わる。**どのポートフォリオの比率かを書く。**
  自分が持っていない銘柄なら「テンバガーXでは3.8%（自分は未保有）」のように書く

### 持株の増減を書く前に、分割を疑う

役員や大株主の株数が期のあいだで2倍・半分に動いていたら、**まず株式分割の
調整がずれていないかを確かめる。** 実際にGENDAで、片岡尚の持株が
21,091,200→11,122,800→25,600,600株と乱高下しているように見え、それを
「経営陣が売り買いしている」と書いてしまった。調べると分割調整のずれで、
実際は21,091,200→22,245,600→25,600,600と増やし続けていた。

```bash
python -c "import yfinance; print(yfinance.Ticker('9166.T').splits)"
```

`holdings_service` は役員の基準日（提出日か期末か）を銘柄ごとに自動で選ぶが、
それでも合わないことがある。**2倍・半分の動きは、売買よりも分割を先に疑う。**

### 売ったと書く前に、なぜ売ったかを読む

株数が減っていても、それが「創業者が降り始めた」とは限らない。
**フィットイージー(212A)で一度これを間違えた。** 國江仙嗣が3,242,100→1,427,200株と
半分以下にしているのを見て「上場2年目に個人保有株の56%を売却」と書いたが、
開示の本文を読むと**東証プライムの上場基準「流通株式比率35%」を満たすための
売出し**だと明記されていた。議決権は68.90%→55.25%で支配は維持、
ロックアップも掛かっている。意味がまるで違う。

株数が減っていたら、順に確かめる。

1. 分割調整のずれではないか
2. **関係者間の移動ではないか。** 創業者が資産管理会社に持ち替えると、
   個人の株数だけが減る。画面では「関係者間で移動」と出る（3300がその例で、
   清水剛→TSコーポレーションに1,823,636株）
3. 大量保有報告書の「なぜ」に何と書いてあるか（画面の「5%超の売買」タブ）
4. その時期の適時開示の本文に理由が書かれていないか（`disclosure_pdf.py`）

4まで見て理由が分からなければ、**分からないと書く。** 推測を断定で書かない。

## やってはいけないこと

- 抽出した数字と混ぜる。画面では「AIによる解釈」のバッジで区別している
- 判定を書かずに解説だけ置く
- 経営陣の持株の増減を見ずに「長期保有」と書く
- **持株が減ったのを見て、理由を確かめずに「売り抜けた」と書く**
- **競合を取り直さずに順位を書く**（手順0）。「競合4社で最小」が
  画面に出ていない相手との比較になる
- 競合の数字が自社より桁違いに良い／悪いときに、そのまま書く。
  持株会社の単体を拾っていた、といった取り違えがある
  （212Aに「カーブスHの営業利益率84%」と書いていたが、連結では16.9%だった）
